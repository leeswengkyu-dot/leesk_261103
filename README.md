# ARGUS-K (로컬 실행판 MVP v1.1)

북한 등 안보 관련 공개정보를 매일 자동 수집하고, 중복을 정리하고, **출처가 붙은 사실·추정 구분 요약**과 지도로 전일 대비 변화를 보여주며, **사람이 검토·승인한 내용만** 지휘관 브리핑으로 게시하는 로컬 웹 도구입니다. 데이터는 이 PC의 SQLite 파일(`data/argus.db`)에만 저장됩니다.

## 실행 방법 (명령 3개)

필요한 것: **Node.js 20 LTS 이상** (Windows 10/11, macOS), Chrome 또는 Edge

```bash
npm install
copy .env.example .env.local     # macOS: cp .env.example .env.local   (AI를 쓸 때만 내용을 채우면 됩니다)
npm run start:local
```

처음 실행은 빌드 때문에 1~2분 걸립니다. 다 되면 브라우저에서 **http://localhost:3000** 을 여세요. `data/argus.db` 가 자동으로 만들어지고 수집 출처가 등록됩니다.

- 종료: 실행한 터미널에서 `Ctrl + C`
- 07:00 이후에 처음 켜면 "놓친 아침 수집"이 자동으로 한 번 실행됩니다. 자동 수집은 **앱이 켜져 있을 때만** 동작하므로 매일 07:00 전에 앱을 켜 두거나 PC를 절전 없이 켜 두세요.

## `.env.local` 설정

| 이름 | 설명 | 기본값 |
|---|---|---|
| `ANTHROPIC_API_KEY` | Claude API 키. **없어도 실행됩니다** (아래 "AI 없이 쓰기" 참고) | 없음 |
| `AI_MODEL` | 사용할 모델 ID (예: `claude-sonnet-5-5`). 키와 함께 지정해야 AI가 켜집니다 | 없음 |
| `AI_DAILY_LIMIT` / `AI_BATCH_LIMIT` | 하루 AI 호출 상한 / 수집 1회당 AI 처리 기사 수 | 300 / 100 |
| `COLLECT_CRON` | 자동 수집 시각 (cron 식, 한국 시간) | `0 7 * * *` |
| `DB_PATH` | DB 파일 경로 | `./data/argus.db` |
| `PORT` | 포트 | `3000` |
| `EDIT_PIN` | 내부망 공유 모드용 PIN (6자리 이상) | 없음 |

### AI 없이 쓰기
API 키가 없으면 수집된 기사는 **키워드 규칙**으로 지역·유형을 추정해 수집함에 들어가고(위치는 "미상"), 요약은 실무자가 직접 쓰거나 CSV(사전 생성 요약)로 넣습니다. 브리핑 초안은 승인된 문장만으로 규칙 기반으로 만들어집니다. 키를 넣으면 위치·유형 추출, 요약 문장 생성, 충돌 제안, 브리핑 초안 작성에 AI가 쓰입니다. AI가 만든 결과는 모두 **[미확인]/[사실 제안]** 으로 시작하며 사람이 승인해야 합니다.

## 내부망 공유 모드 (선택)

같은 네트워크의 다른 PC에서 보려면:

1. `.env.local` 에 `EDIT_PIN=숫자6자리이상` 설정
2. `npm run start:lan`
3. 다른 PC 브라우저에서 `http://<실행 PC의 IP>:3000` (IP 확인: `ipconfig`)

열람은 PIN 없이 가능하고, 수집·편집·게시·백업 등 **쓰기 작업에는 PIN**이 필요합니다(같은 IP에서 5회 틀리면 10분 잠금). Windows 방화벽 허용 창이 뜨면 "개인 네트워크"를 허용하세요.

## 화면

- **상황판** — 지역별 신규·지속·확대·종료 건수와 경보 배지, 지도 + 목록(양방향 연동), 필터, 사건 상세 패널(라벨별 요약·출처·충돌·중복 후보·검토 완료)
- **브리핑** — 보기 / 편집 / 발표(전체화면). "AI 초안 생성 → 문장 수정 → 브리핑 게시". 게시 전 검증(출처 없는 문장·검토 미완료 사건 참조·[사실] 조건)을 통과해야 게시됩니다.
- **데이터·설정** — 지금 수집, 수집 기록, 출처 활성 토글, CSV 업로드, AI 설정, 백업

## 핵심 규칙 (PRD 11·16·17장)

- 모든 요약 문장은 라벨 1개 + 출처 1개 이상. 출처 없는 문장은 자동으로 [미확인]
- **[사실]** 은 ① 서로 독립적인 출처 2개 이상, 또는 ② A등급(공식) 출처 1개 + 실무자 승인일 때만 저장됩니다. 당사자(관영매체) 기사만 있으면 [당사자 주장]만 가능
- 같은 URL은 한 번만 저장, 원문 본문은 저장하지 않음(제목·설명·링크만)
- 중복은 후보만 제안하고 **병합은 사람이 확정**
- 검토 완료된 사건만 브리핑에 들어갑니다

## 백업·복원

- 당일 첫 수집 전에 `data/backups/argus-YYYYMMDD.db` 가 자동 생성됩니다(최근 14개 보관). 설정 화면의 [지금 백업]으로 수동 백업도 됩니다.
- 복원: 앱을 끈 뒤 백업 파일을 `data/argus.db` 로 복사하고(`argus.db-wal`, `argus.db-shm` 이 있으면 삭제) 다시 실행합니다.

## 개발·테스트

```bash
npm run seed:dev   # 개발용 DB(data/argus-dev.db)에 합성 데이터 40건 넣기 (운영 DB에는 넣지 않음)
npm run dev        # 개발용 DB로 개발 서버 시작 (http://localhost:3000, 자동 수집 없음)
npm test           # [사실] 조건·신뢰도·경보·중복 규칙 단위 테스트
```

## 수집 출처 (`data/feeds.seed.json`)

연합뉴스 북한, 38 North, NK News, UN News(평화·안보), IAEA, Yonhap(English), BBC 중동, Kyiv Independent.
RSS를 확인하지 못해 제외한 출처: **통일부 보도자료**(RSS 주소 404), **ISW**(접근 403). 대체 출처가 필요하면 `data/feeds.seed.json` 에 추가하세요(처음 DB를 만들 때 반영되며, 이미 만든 DB에서는 설정 화면의 활성 토글만 지원).

## 문제 해결

| 증상 | 조치 |
|---|---|
| 포트 3000이 사용 중 | `.env.local` 에서 `PORT=3001` 로 변경 |
| 지도가 안 보임 | 인터넷(OpenStreetMap 타일) 확인. 목록·상세는 계속 사용 가능 |
| "DB를 열 수 없습니다" | `data/backups` 의 최근 백업으로 복원 |
| `npm install` 중 better-sqlite3 오류 | Node.js 20 LTS 이상인지 확인 후 재시도 |
